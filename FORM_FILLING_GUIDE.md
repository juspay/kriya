# Form integration

The current integration guide is [Browser execution engine](docs/integration/browser-engine.md).
For goal-driven form workflows, use [Application lifecycle](docs/integration/lifecycle.md) and
[Security and verification](docs/integration/security.md).

Native forms, explicit form registration and compatible framework objects remain supported.
Framework-private detection and custom widgets need validation against your own application.
Kriya no longer ships a ReScript binding or imports React/React Final Form.
